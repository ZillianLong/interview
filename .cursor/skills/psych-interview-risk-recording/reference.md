## 八维 · 等级描述速查

| 维度 | 低 | 中 | 高 |
|------|----|----|-----|
| 抑郁悲观 | 情绪偶有低落，注意力基本稳定，做事投入正常 | 情绪时常低落，注意力容易分散，做事投入不足 | 情绪长期低落，注意力难集中，做事明显没劲 |
| 焦虑不安 | 平时较少多想，心里基本踏实，确认后很少再问 | 遇事容易挂心，心里不太踏实，确认后还会再问 | 经常放心不下，心里很难踏实，确认多次仍不安心 |
| 冲动违规 | 基本能守规矩，很少与人起冲突，出错后愿意改正 | 有时不按规矩，容易与人起争执，出错后不太愿改 | 经常不守规矩，动不动就起冲突，出错后很难改过 |
| 行为古怪 | 说话略显特别，想法和别人差不多，配合基本正常 | 说话有些难懂，想法有些不同，别人不太愿配合 | 说话常难听懂，想法比较特别，别人较少愿配合 |
| 偏执多疑 | 很少怀疑别人，不太乱猜用意，合作推进顺利 | 有时怀疑别人，容易往坏处想，沟通需要反复 | 经常怀疑别人，总觉得被人算计，合作推进费劲 |
| 喜怒无常 | 情绪基本稳定，对事反应正常，对人态度平稳 | 情绪起伏明显，对事反应偏大，对人忽冷忽热 | 情绪变化很快，对事反应激烈，对人态度反差大 |
| 刻板固执 | 新做法能跟上，事情敢交人，做事效率基本正常 | 新做法跟得较慢，事情不太放手，反复检查影响效率 | 新做法很难适应，事情基本不放手，经常重复返工 |
| 妄想离奇 | 能分清现实想法，做事判断正常，用工风险基本可控 | 有时分不清现实和猜想，做事判断偶有偏差，用工需留意 | 常分不清现实和幻想，做事判断容易出错，用工风险较高 |

给出等级时，**同时写出该格「描述」原文**（填入 Excel「等级描述」列）。

## 八维考察点一览（面试信号 → 等级）

先按考察点分析，再对照上表选 **低/中/高**（可介于两档时取较高并注明不确定）。

| 维度 | 考察点1 | 考察点2 | 倾向等级提示 |
|------|---------|---------|--------------|
| 抑郁悲观 | 举例回应 | 说话过程 | 两考察点均未命中→低；一条命中→中；两条明显或持续→高 |
| 焦虑不安 | 压力感受 | 压力应对 | 情境性压力+有应对→低；反复担心/睡眠受影响→中；严重不符+无应对→高 |
| 冲动违规 | 规则感受 | 实际做法 | 守规矩→低；单次变通→低~中；反复不守且无所谓→中高 |
| 行为古怪 | 表达条理 | 对方反应 | 正常分歧→低；需反复问才懂→中；明显混乱+他人回避→高 |
| 偏执多疑 | 过度解读 | 看待解释 | 偶尔多想→低；多发/坚持「在点我」未核实→中；广泛被害化→高 |
| 喜怒无常 | 事件程度 | 消气时长 | 单次能收口→低；反应偏重且久难消→中 |
| 刻板固执 | 交托态度 | 做完惦记 | 放心分工→低；交出去后反复检查/重做→中；必须自己做/反复返工→高 |
| 妄想离奇 | 言语逻辑 | 注意状态 | 全程自然观察后对照上表低/中/高（无单独主问） |

## 风险等级判定原则

### 低

- 两条考察点均未出现较明确风险信号；或
- 仅有轻微、单次、可情境解释的表现；或
- 信息不足无法支撑更高等级（分析列标「不明确」时，优先**低**）。

### 中

- **任一条**考察点与专家信号**较明确吻合**；或
- 候选人自述与行为呈中等强度风险线索，且与「中」列描述大体相符。

### 高

- **两条**考察点均明显吻合；或
- 单条信号**强度高、反复出现、无情境缓冲**；且与「高」列描述大体相符。

分析列仍用模板：

```
【四字关键词】原话/过程 → 对照专家信号（命中/未命中/不明确）→ 结论
```

## 每维结束 · 候选人反馈收集（必做）

面试官给出本维 **考察点分析 + 风险等级 + 等级描述** 后，**必须**向回答人提两个问题（一次只问，等作答）：

**① 自我报告（一致性）**（对候选人**不说维度名**）

> 结合你自己的真实感受：刚才这道题相关的评估是「{低/中/高}」——{等级描述一句}。这和你对自己的体验是否一致？请说明一致或不一致的原因。没有特别感受可以说「无」。

**② 对题意见**

> 对刚才这道题（包括主问和追问），你有什么意见或反馈？没有则说「无」。

记录规则：

| 列 | 内容 |
|----|------|
| 候选人自我报告 | 原话或忠实摘要；答「无」则填 `无` |
| 候选人对题反馈 | 原话或忠实摘要；答「无」则填 `无` |
| 判断不一致说明 | 仅当自我报告与面试官等级**不一致**时填写：双方判断、原因、是否需复核；一致则留空或填 `一致` |

## 专家材料反馈 · 双来源写法

每个维度须分块标注来源：

- **【面试官反馈】** 题本/考察点/等级判断/改进建议
- **【候选人反馈】** 自我报告（一致性）+ 对题意见（引用原话）
- **【判断一致性】** 一致 / 不一致 + 简要说明

自我报告与面试官等级不一致的维度，在反馈文件中**加粗或单独小节**说明，并与 Excel「判断不一致说明」列一致。

## 易混维度

分析列末尾可加：`可能触及 XX 维，本行仍按 YY 维记录。`

| 易混对 | 区分要点 |
|--------|----------|
| 冲动违规 vs 刻板固执 | 冲动：规矩束缚/不守规矩；刻板：交托不放心 |
| 焦虑不安 vs 抑郁悲观 | 焦虑：压力与应对；抑郁：满意与自我评价 |
| 偏执多疑 vs 刻板固执 | 偏执：解读他人用意；刻板：分工控制 |
| 行为古怪 vs 抑郁悲观 | 行为古怪：对方反应与条理；抑郁：自我评价 |
| 焦虑不安 vs 刻板固执 | 焦虑：未发生/不确定事的挂心；刻板：已交出去/已做完的事反复检查。**勿因自述「反复确认已完成工作」单独给焦虑升档** |

## 反馈收集 · 升档纪律（2026-05-27）

自我报告与初判不一致时：

| 情况 | 处理 |
|------|------|
| 自述「反复打开已确认材料、心里不踏实」 | 优先对照**刻板固执**维；**焦虑不安维持初判低** |
| 自述与初判不一致但信号更贴近其他维 | 维持初判，在「判断不一致说明」记录原因 |
