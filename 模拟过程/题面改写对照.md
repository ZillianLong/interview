# 阶段 C · 题面定稿（用户风格）

## 风格要点

- 场景词自然嵌入：学习、实习或是日常工作里 / 平时上学、实习或者上班期间 / 日常学习工作里
- 邀请语多样：麻烦讲一讲、结合具体一件事、拿一次真实经历具体讲讲、简单讲讲来龙去脉、具体说说你的做法
- 可先铺情境再发问：焦虑、行为古怪、刻板固执
- 主问可含具体讲述要求，追问落脚内心体验

## 7 题定稿

| 维度 | 主问 |
|------|------|
| 抑郁悲观 | 在学习、实习或是日常工作里，有没有哪件事做完之后自己特别满意…麻烦讲一讲这次经历，说说当时具体是什么情形。 |
| 焦虑不安 | 就算手头事情都安排妥当…你通常会用什么方式调整自己，慢慢平复心态走出来？ |
| 冲动违规 | 平时上学、实习或者上班期间，有没有…被长辈、领导或是同事指出问题的经历？结合具体一件事，说说当时发生了什么。 |
| 行为古怪 | 和同学、同事一起商量事情时…说说你遇到过这样的具体经历。 |
| 偏执多疑 | 日常学习工作里…你第一时间心里是什么想法？拿一次真实经历具体讲讲。 |
| 喜怒无常 | 最近有没有发生过让你情绪波动很大…简单讲讲整件事的来龙去脉。 |
| 刻板固执 | 遇上做事流程、惯用方法突然改变…你平时都是怎么快速适应过来的？具体说说你的做法。 |
