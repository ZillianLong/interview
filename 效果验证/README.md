# 效果验证

HR 按专家题本执行面试后的产出目录（由 `psych-interview-risk-recording` 技能生成）。

| 子目录 | 文件命名 | 说明 |
|--------|----------|------|
| `面试记录/` | `面试记录_{候选人标识}.xlsx` | 每位候选人一份，12 列（含低/中/高、候选人自我报告与对题反馈） |
| （参照） | `维度得分描述.xlsx` | 各维低/中/高等级描述原文 |
| `专家材料反馈/` | `专家材料反馈_{候选人标识}.md` | 对 [面试观察.md](../面试观察.md) 的可观察性与改进建议 |

**推荐用法：** 在 Cursor 中调用 `psych-interview-risk-recording` → 输入候选人姓名 → HR 逐维提问、你作答 → 结束后自动生成本目录下的 xlsx 与反馈 md。

使用前须确认 `候选人标识`，避免覆盖已有文件。
