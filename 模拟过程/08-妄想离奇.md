# 妄想离奇 · 模拟过程

## 说明

**不建议直接提问，面试中自然观察。**

## 关键考察点（面试过程中自然观察，不作结论）

| 观察点 | 留意什么 |
|--------|----------|
| 言语逻辑 | 言语逻辑混乱、答非所问；前后接不上，话题突然跳开 |
| 注意状态 | 注意力明显不集中；叫一声才回过神，对视少、反应慢半拍 |
| 独自言语 | 有自言自语，或像在无对象地对话、凭空对话 |
| 情感协调 | 情感表达与内容不协调；如说的是难过的事却在笑 |

**注意：** 观察记录，不作心理诊断结论。

## 过程观察示例（非固定提问引出）

- 问上一题的工作经历，回答跳到另一段不相关的内容，追问仍接不上 → **言语逻辑**
- 面试官叫名字或重复问题，过一会儿才回过神 → **注意状态**
- 等待或思考时出现对着空气说话、像在跟不存在的人交流 → **独自言语**
- 讲述受挫、被批评等事时面带笑容或语气轻快 → **情感协调**
