# 心理风险维度 · 学习笔记

## 用途

阶段 A 的专业研究**必须落盘**为本目录下的学习笔记，再进入出题、模拟、考察点设计。笔记不是给 HR 看的，是给撰写者建立维度理解用的。

## 每篇笔记必含章节

1. **维度定义**（来自 `维度定义.xlsx`）
2. **DSM-5 核心要点**（检索权威来源后归纳，标注检索日期）
3. **理解线**：典型表现、与相似维度的边界
4. **体验线**：代入体验者在学习/实习/工作中的第一人称感受
5. **工作风险线**：来自 `工作表现.xlsx` 的低/中/高表现（子维度 + 摘要）；对照 [工作风险对照.md](工作风险对照.md)
6. **出题启示**：主问应触什么、应避什么
7. **易混辨析**（若适用）

## 撰写原则

- 笔记服务于「理解维度 → 设计行为题 → 模拟 → 反推考察点」，不直接复制 DSM 条目进 Excel。
- 检索来源优先：APA/DSM-5-TR、NCBI StatPearls、Merck/MSD Manual、Mayo Clinic 等。
- 每完成一维笔记，在阶段 B 出题前须重读该维笔记及易混维笔记。
- 出题须遵守 **题面四原则**（见 SKILL.md）：不预设行为、语病自检、候选人能答、勿第三人铺垫。

## 与 skill 工作流的关系

```
阶段 A：读 维度定义 + 工作表现.xlsx + DSM → 写入 学习笔记/0X-维度.md
阶段 B：读笔记 + 工作风险对照 → 设计主问/追问初稿
阶段 C：题面改写（语病、降 AI 感、跨维去模板化）→ 写入 模拟过程/
阶段 D：读笔记体验线 → 用改写后题面模拟应答
阶段 E：理解线 + 工作风险线 + 模拟 → 关键考察点（与工作表现子维度对应）
阶段 F：写入 Excel
```
