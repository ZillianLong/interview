# 专家材料反馈 · 模拟-抑郁悲观样例

> **示例数据**：来自 [模拟过程/01-抑郁悲观.md](../../模拟过程/01-抑郁悲观.md)，用于校验技能产出格式，非真人面试。

## 总评

题本整体能通过「满意经历 + 事后感受」引出自我评价线索，与专家考察点对应清晰。本次示例中**抑郁悲观**维度信号最强：候选人主问即出现「谈不上特别满意」、追问「高兴谈不上」，与两条考察点均吻合。**最弱**暂未测全其余 7 维（本文件仅对抑郁悲观做深评，其余维待真人面试补全）。

## 分维度评价

### 抑郁悲观

1. **题本与追问：** 主问成功引出实习整理资料经历；专家追问「做完之后心里是什么感受」有效，候选人原话「也就是松一口气吧，高兴谈不上」直接暴露低满意感，无需 HR 补充追问。
2. **考察点1（举例回应）：** 信号可辨。原话「其实也谈不上特别满意，就是大家一起做的」与专家清单「完成不错仍觉得不过如此、强调团队功劳」高度吻合。
3. **考察点2（说话过程）：** 主问前「嗯……（停顿）」与答追问时的平淡语气，与「停顿久、语调偏低」一致；建议 HR 在「候选人回答」栏用括号记下过程，避免只记文字漏掉过程信号。
4. **改进建议：** 若候选人回答「想不起来任何满意的事」，可在题本或 reference 补充追问中增加「有没有一件做完觉得还行的，哪怕不大」以降低空答率。

### 妄想离奇

1. **题本与追问：** 不出题的设计合理；HR 需在整场中分散观察，避免只盯最后一维。
2. **考察点1（言语逻辑）：** 示例中各题能接上，未见明显混乱；观察点可辨。
