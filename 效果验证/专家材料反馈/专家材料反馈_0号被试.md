# 专家材料反馈 · 0号被试

## 总评

题本整体能引出可观察信号，尤其**偏执多疑**维与候选人自述高度吻合（领导泛谈「超出期待」即联想绩效对话、坚持「在点我」）。**抑郁悲观**维表现最好：长段成就叙述 +「挺牛的」与考察点「低满意/贬低自我」相反，题本有效区分。本次最弱检出在**冲动违规**、**刻板固执**：前者直接否认不合理规则，后者分工回答过简，靠追问才补全。

## 分维度评价

### 抑郁悲观

1. **题本与追问：** 主问成功引出 AI 小语种项目长叙述；追问「心里感受」得到「挺牛的」正面评价，与风险信号相反，题本区分度好。
2. **考察点1（举例回应）：** 可辨；原话「觉得自己挺牛的」与「讲不出满意/不过如此」清单相反。
3. **考察点2（说话过程）：** 线上文字无法观察停顿叹气；内容完整度高，过程信号弱。
4. **改进建议：** 线下面试时在记录栏增加「过程」括号（停顿、语气），避免漏掉说话过程考察点。

### 焦虑不安

1. **题本与追问：** 「最近特别有压力」引出睡前失眠与求职焦虑，追问「怎么应对」有效。
2. **考察点1（压力感受）：** 可辨；原话「也不知道是不是压力大」显示自述克制，压力与求职情境基本匹配，未明显夸大。
3. **考察点2（压力应对）：** 可辨；「放空脑子、少喝咖啡，好一点」说明有应对，本题本不易误判为高风险。
4. **改进建议：** 考察点可补充「反复失眠超过一周」等更可观察阈值，减少与一般求职焦虑混淆。

### 冲动违规

1. **题本与追问：** 主问得「都挺合理」；补充追问才引出守夜回家例子，说明单靠主问易空答。
2. **考察点1（规则感受）：** 本次未命中。
3. **考察点2（实际做法）：** 原话「没什么吧、没追责」与清单部分呼应，但属单次变通，题本+追问组合尚可分辨轻重。
4. **改进建议：** 主问后可加预设补充句：「有没有规章你一般照做，但实际会灵活处理的情况？」

### 行为古怪

1. **题本与追问：** 教材讨论例子自然；追问「后来怎么看」得「理解我了、看法不同」，题本未误判古怪。
2. **考察点1（表达条理）：** 可辨，叙述清楚。
3. **考察点2（对方反应）：** 分歧属观点不同，非「困惑、不接话」类信号。
4. **改进建议：** 考察点2可写明「反复描述对方像听不懂我说的话」以区别于正常争论。

### 偏执多疑

1. **题本与追问：** 命中最好；「事后不舒服」+ 领导会上一句话即联想绩效，追问后仍坚持「就是在点我」。
2. **考察点1（事后感受）：** 高度可辨；「我这种情况还挺多的」「挺难绷」。
3. **考察点2（看待解释）：** 高度可辨；「没聊过」「就是在点我」。
4. **改进建议：** 保持现题面；可考虑增加「是否核实过」作为追问备选，便于区分一次误会与持续多疑。

### 喜怒无常

1. **题本与追问：** 顾问冲突例子具体；追问引出「气好一会儿、内心骂她」。
2. **考察点1（事件程度）：** 冲突有双向刺激，难单凭题面判断「事小怒大」，本次偏无风险。
3. **考察点2（持续时长）：** 「好一会儿」+ 边做别事，未达「大半天以上」标准。
4. **改进建议：** 追问可明确问「大概几小时/几天」以便对照持续时长清单。

### 刻板固执

1. **题本与追问：** 主答过简，靠追问才确认「没有不放心、同学更快」；题本对「交托」探测依赖追问。
2. **考察点1（交托态度）：** 追问后可辨为未命中。
3. **考察点2（做法差异）：** 本次未展开差异场景，信息不足。
4. **改进建议：** 主问加一句「当时你怎么分工的、你有没有检查他们的结果？」

### 妄想离奇

1. **题本与追问：** 不出题合理；本次线上文字面试对「注意状态」观察有限。
2. **考察点1（言语逻辑）：** 全程连贯，未命中。
3. **考察点2（注意状态）：** 无法充分观察，不作结论恰当。
4. **改进建议：** 材料中注明线下面试时记录眼神、反应延迟的操作提示。
