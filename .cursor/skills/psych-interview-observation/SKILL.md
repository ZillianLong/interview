## 用户终稿原则（执行时优先）

以下为用户定稿中提炼的**一次性达标**标准；与旧版冲突时，以本段为准。

### 提问

| 原则 | 要求 | 反例 |
|------|------|------|
| **从事件观察** | 用学习/实习/工作中的**具体经历**引出信号 | ❌ 直写维度显性表现（反复多想、快速适应、反应常常差别很大） |
| **典型事件诱发** | 问该维度下的**典型情境**（如分工改动、正常规矩感到压抑），让体验者在该事件中的**看法/态度**自然流露 | ❌ 直接问维度特征（「你多疑吗」「怎么看待规矩」） |
| **普遍情境切入** | 必要时先正常化（「大家都会有压力比较大的时候」） | ❌ 一上来就描述病理体验 |
| **主问结构** | 场景 + 核心问 + 讲述邀请（麻烦讲一讲 / 拿一次经历具体讲讲 / 简单讲讲来龙去脉） | ❌ 只问有没有、不引导讲具体 |
| **高掩饰性** | 问「什么情况下」「当时怎么想」「后来怎么看」 | ❌ 算正常吗、旁人不用操心、讲清楚了别人没接上 |
| **追问** | 在同一经历上延伸**一层**，宜短 | ❌ 切换新场景；不必每题都问「心里感受」 |

### 风格

- 场景词：**学习、实习或是日常工作里** / **平时上学、实习或者上班期间** / **日常学习工作里**
- 称谓：**长辈、领导或是同事**；**同学、同事**
- 邀请语：**麻烦讲一讲**、**结合具体一件事**、**拿一次真实经历具体讲讲**、**简单讲讲来龙去脉**
- 口语、礼貌；默读像真人在说话（走 colloquial skill）

### 考察点

| 原则 | 要求 |
|------|------|
| **数量** | 每维 **2 条**考察点 |
| **格式** | `序号.四字关键词：表现1；表现2` |
| **可观察** | 仅写面试现场能听、能看的内容（说了什么、怎么说的、停顿/语气/肢体） |
| **命名** | 用本题观察切面（压力感受、交托态度、表达条理），**不用**工作表现子维度名 |
| **禁止** | 入职后行为预测、DSM/诊断用语、模拟中未出现的信号 |
| **妄想离奇** | 只写「不建议直接提问，面试中自然观察」+ 过程考察点，**不作结论** |

### 维度切入一览（定稿）

| 维度 | 切入事件 |
|------|----------|
| 抑郁悲观 | 做完特别满意、事后仍觉得很好 |
| 焦虑不安 | 什么情况下特别有压力感 |
| 冲动违规 | 觉得不太合理、感到束缚压抑的规矩 | 大家认为正常的规矩，你却感到束缚 |
| 行为古怪 | 商量事情时对方反应与预想很不一样 |
| 偏执多疑 | 相处时当时没什么、事后越想越不舒服 |
| 喜怒无常 | 特别来气、平复好久才消气 |
| 刻板固执 | 分工、把事交给别人做 |
| 妄想离奇 | 全程自然观察，不出题 |

## 专业知识的双重用途

阶段 A 的研究成果贯穿全流程，分两条线：

| 用途 | 产出 |
|------|------|
| **理解线** | 维度核心内涵 → 主问/追问应覆盖哪些心理体验 |
| **体验线** | 代入心理体验者 → 模拟怎么答 → 反推 HR 可观察的具体信号 |
| **工作风险线** | `工作表现.xlsx` 低/中/高风险 → **理解维度在工作中的影响**（阶段 A/B 出题参考，**不直接写入考察点**） |

**关键原则：** 考察点不是从 DSM 或工作表现条目直接翻译，而是 **基于本题问答 + 模拟体验者作答**，提炼 HR 在面试现场能直接看到/听到的线索。**不写入职后工作行为**（如接活反应、规则执行、团队协作配合度等），只写候选人 **怎么答、答什么、说话过程怎样**。

## 题面：行为化 + 口语化 + 校招社招通用

### 不预设行为

- 「有没有…经历/哪件事」**可以**，但须配 **讲述邀请**；更推荐 **情境描述**（「有些…别人觉得正常，你本人却…」）+ 结合具体一件事
- 避免**光问有没有、不引导讲具体**；避免「印象比较深的是哪一次」默认已有
- 题面不写维度显性词（见「从事件观察」）；候选人答「没有/想不起来」也是有效观察

### 行为化（基于真实经历）

主问/追问必须引导候选人 **讲过去实际发生过的事**，而非假设或泛化态度。详见 [reference.md](reference.md) 行为化原则。

### 口语化（必须走 colloquial-interview-blue-collar）

撰写主问/追问前 **必须读取并执行** `colloquial-interview-blue-collar` 原则，写完后 **默读一遍**，像原稿里的真人面试官在说话。

**用户风格参考**（定稿范例见 [examples.md](examples.md)）：
- 场景词自然嵌入：「学习、实习或是日常工作里」「平时上学、实习或者上班期间」
- 邀请语多样：「麻烦讲一讲」「结合具体一件事」「拿一次真实经历具体讲讲」「简单讲讲来龙去脉」
- 可先铺情境再发问；主问可含讲述要求，追问落脚内心体验

### 题面原则（全维度必守）

1. **高掩饰性**：题面**不点破**维度特征（不写「担心但旁人不用操心」「讲清楚了别人没接上」「算正常吗」等替候选人或旁人定性的话）
2. **不预设行为**：不用「有没有哪次/哪件事/遇到过吗」「印象比较深的是哪一次」；不用「有的人会……你有吗」；不问「你觉得正常吗 / 算不算正常 / 能接受吗」
3. **语病自检**：完整问句，疑问尾清楚；写完后默读通顺
4. **候选人能答**：有具体场景，听得懂、知道从哪说起
5. **勿用第三人铺垫**：不用「有的人/每个人」作题面引入
6. **引入不模板化**：全维度不重复同一场景开头；场景词（学习、实习或工作）自然嵌入句中，不机械置顶
7. **体验者视角**：从本人感受出发问「心里怎么想/什么感受」，不替对方贴标签

### 校招社招通用

题面 **不得仅假设全职工作语境**。校招生可能只有学习、社团、实习经历。

| 推荐 | 避免 |
|------|------|
| 学习、实习或工作中 | 仅写「工作中」「您的单位」 |
| 负责人或对方、周围的人 | 仅写「领导」「同事」 |
| 和同学、同事或其他人一起 | 仅写「和同事」 |
| 那边明确要求、按要求应该 | 仅写「单位要求」「规章制度」 |

### 零行业绑定

不出现产线、店里、跑单等业态词，不用「不管是 A 还是 B」式行业并列。详见 [reference.md](reference.md) 禁用词表。

## 六阶段工作流（每维度独立执行；全部维度时须做跨维改写检查）

### 阶段 A — 研究 + 学习笔记落盘

1. 读取 `维度定义.xlsx` 中当前维度的描述、核心内涵、DSM-5 关联。
2. 读取 `工作表现.xlsx` 中当前维度的**低/中/高**工作风险及子维度（如规则执行、干活习惯），写入学习笔记 **工作风险线**；对照表见 [工作风险对照.md](../../学习笔记/工作风险对照.md)。
3. 检索 DSM-5-TR 核心症状与鉴别要点（见 reference.md 检索关键词）；Web 搜索权威资料（APA、NCBI StatPearls、Merck/MSD Manual 等）。
4. **将研究结果写入 `学习笔记/0X-维度名.md`**（见 [学习笔记/00-说明.md](../../学习笔记/00-说明.md)），每篇必含：维度定义、DSM-5 核心要点（标注检索日期）、**理解线**、**体验线**、**工作风险线**、**出题启示**、**易混辨析**。
5. 阅读 `面试原稿.docx` 面试官内部讨论，提取可迁移观察线索，可补充进笔记。
6. 若用户提供咨询记录，优先用于体验线；有则读，无则靠权威资料第一人称描述。

**阶段 B 开始前必须重读** 当前维度学习笔记 + 易混维度笔记。

### 阶段 B — 设计主问与追问（初稿）

1. **重读** `学习笔记/0X-维度名.md`、`用户终稿.md` 及易混维笔记，确认主问从**具体事件**切入、不误触其他维（如刻板固执问「交给别人做」，勿问「换流程怎么适应」；冲动违规问「被指出」，勿与刻板共用「习惯 vs 要求」）。
2. 从理解线罗列 **2 个**关键观察切面（定稿每维 2 条考察点）；**不用**工作表现子维度名作考察点关键词。
3. 写出主问、追问**初稿**（允许尚未完全口语化；考察目标正确即可）。
4. **妄想离奇** 不设题，只写不适合原因与过程观察点，跳过阶段 C，直接进入阶段 D（自然观察类考察点）。
5. **自检**：行为化、校招社招通用、高掩饰性方向正确；无业态词。

**阶段 C 开始前**：初稿写入 `模拟过程/0X-维度.md` 的「初稿」小节，或直接作为改写输入。

### 阶段 C — 题面改写（必做）

在初稿基础上，**专门做一轮题面改写**。必须读取 `colloquial-interview-blue-collar` 并对照 `面试原稿.docx` 的问法风格。

**本阶段只做题面**（主问 + 追问），不改考察点骨架。

#### C1. 语病与通顺

- 默读全文，主问**一句讲完**；追问各一句，衔接自然
- 修正：缺「吗/什么/哪」、破折号戛然而止、指代不明（「那样做」「这种情况」）、重复用词

#### C2. 降 AI 感

- 删改题库腔：「请回忆一次」「跟我分享」「具体说说」「有的话，哪次印象比较深」
- 删改审问腔：「你说说」「你回想下」「被提醒过吗？有的话」
- 删改拼接腔：「先从…聊起。哪件事…？」「A。B？」两段硬接
- 保留邀请式但不过量：「请说说」全库不宜每题都以它开头

#### C3. 降维度内模板化

- 同一维度主问与追问不重复同一套词（如主问、追问都写「请说说有没有哪次」）
- 追问从主问**自然延伸**，像对话接话，不是另起一题

#### C4. 跨维度去模板化（全部维度时必做）

完成 7 个可出题维度后，**并排列出全部主问**，检查：

| 检查项 | 要求 |
|--------|------|
| 开头句式 | 不宜 3 题以上共用同一开头（如全是「请说说，有没有哪次」） |
| 场景引入 | 不宜 4 题以上都以「在学习、实习或工作中」起句 |
| 疑问结构 | 主问句式应有变化：邀请式 / 场景嵌入式 / 时间锚点式（最近一次…）等 |
| 追问结构 | 不宜全部「被提到以后…」「做完以后…」同一模式 |

不合格则回到 C1–C3 改写**该维或重复最多的句式**的那几维，直至 7 题读起来像同一位面试官在不同话题下自然发问，而非同一模板换关键词。

#### C5. 改写产出

- 改写后题面写入 `模拟过程/0X-维度.md` 的「主问 / 追问」小节（覆盖初稿）
- 可选：在 `学习笔记/0X-维度.md` 的「出题启示」末尾记一句「改写要点」

详见 [reference.md](reference.md) 题面改写检查表。

### 阶段 D — 模拟应答（心理体验者身份）

内部步骤，默认不写入 Excel，**须写入 `模拟过程/` 目录**（每维度一个 md 文件，见 [模拟过程/00-说明.md](../../模拟过程/00-说明.md)）。模拟前 **重读** `学习笔记/` 中当前维 **体验线**，并使用 **阶段 C 改写后** 的题面。

1. **模拟 1**：以「有该维度心理体验的蓝领」身份答主问；自然流露内心感受、自我评价方式、信息展开程度、情绪过程。
2. **调整追问**：对照模拟 1，找出内心体验尚未暴露的缺口。
3. **模拟 2**：同一身份答追问，进一步暴露内心体验线索。

**模拟自检：** HR 坐在对面，能从对话里看到/听到什么？这些信号即阶段 D 素材。

### 阶段 E — 反推关键考察点

基于理解线 + 模拟（实际信号），**从本题问答反推**：

- 格式：`序号.四字关键词：可观察表现1；可观察表现2`
- **每维 2 条**；详见 [用户终稿.md](../../用户终稿.md)
- 每条描述必须是 HR **坐在面试间里**能直接对照的内容：候选人说了什么、怎么说的、需不需要反复追问
- 禁止写模拟中未出现、现场无法捕捉的内容；禁止写「入职后会怎样」的工作行为预测
- 兼顾 **言语内容**（原话倾向、归因方式、感受用词）与 **过程表现**（停顿、叹气、语速、需多次追问）
- 每条应能回溯到模拟片段或原稿类似观察
- 梯度（轻→重）体现在 **同一观察切面上答得有多明显**，而非引用工作风险等级

### 阶段 F — 写入 Excel

用 Python（openpyxl/pandas）写入 `面试观察.xlsx`：

| 维度 | 面试观察 |
|------|----------|

单元格模板：

```
问题：[口语化主问]

追问：[口语化追问]

关键考察点
1.[子维度]：[表现1]；[表现2]
2.[子维度]：[表现1]；[表现2]
```

设置 B 列自动换行，列宽 80–100。

批量写入可运行：`python scripts/write_excel.py`（更新 `面试观察.xlsx`）。

## 执行粒度

- 默认一次处理一个维度，完成后再进下一维。
- 用户说「全部维度」时，按 `维度定义.xlsx` 顺序处理 8 维；**7 题全部改写完成后**，必须做一次阶段 C4 跨维对照再写入 Excel。
- 每完成一维，更新 Excel 对应行并验证文件存在。
