## 用户终稿：提问方式

### 核心逻辑

**从具体事件观察心理风险，不直白询问维度显性表现。**

| 维度 | 切入事件（问什么） | 不写什么 |
|------|-------------------|----------|
| 抑郁悲观 | 特别满意、事后仍觉得很好 | ❌ 直接问「悲观」「没动力」 |
| 焦虑不安 | 什么情况下特别有压力感 | ❌ 「反复多想、久久没法释怀、怎么平复心态」 |
| 冲动违规 | 大家认为正常的规矩，你却感到束缚 | ❌ 「做法与要求不一样」「不守规则」「爱违规」 |
| 行为古怪 | 商量时对方反应与预想很不一样 | ❌ 「反应常常差别很大」（预设频率） |
| 偏执多疑 | 搭班相处中事后还会想起的事 | 聊天说笑、你怎么理解（掩饰性弱） |
| 喜怒无常 | 最近情绪波动大或憋屈难受 | ❌ 「情绪不稳定」「易怒」 |
| 刻板固执 | 分工、把事交给别人做 | ❌ 「流程改变、怎么快速适应」 |
| 妄想离奇 | 不出题，全程自然观察 | ❌ 任何固定主问 |

### 主问结构（三件套）

1. **场景**：学习、实习或是日常工作里 / 平时上学、实习或者上班期间 / 日常学习工作里  
2. **核心问**：什么情况下 / 当时怎么想 / 有没有…经历  
3. **讲述邀请**：麻烦讲一讲… / 拿一次经历具体讲讲 / 结合具体一件事… / 简单讲讲来龙去脉  

### 普遍情境铺垫（按需）

- 焦虑不安：「大家都会有觉得压力比较大的时候」——先正常化，再问「什么情况下特别有这种感觉」

### 追问

- 在同一经历上延伸**一层**，宜短  
- 示例：「被指出以后你怎么想的」「你后来怎么看」「一般会怎么应对」「会不会再去检查一遍」  
- **不必每题都问「心里感受」**；刻板可合并：「别人做法不同怎么看 + 交出去后检不检查」

## 用户终稿：考察点

### 数量与格式

- 可出题维度：**2 条**
- 妄想离奇：**4 条**过程观察
- 格式：`序号.四字关键词：表现1；表现2`

### 写什么

| 写 | 不写 |
|----|------|
| 候选人说了什么（归因、用词、举例内容） | 工作表现子维度名（规则执行、干活习惯） |
| 怎么说的（停顿、叹气、语速、语气、肢体） | 入职后会怎样的行为预测 |
| 需不需要反复追问才讲清 | DSM / 诊断标签 |

### 定稿考察点命名对照

| 维度 | 考察点 1 | 考察点 2 |
|------|----------|----------|
| 抑郁悲观 | 举例回应 | 说话过程 |
| 焦虑不安 | 压力感受 | 压力应对 |
| 冲动违规 | 规则感受 | 实际做法 |
| 行为古怪 | 表达条理 | 对方反应 |
| 偏执多疑 | 事后感受 | 看待解释 |
| 喜怒无常 | 事件程度 | 持续时长 |
| 刻板固执 | 交托态度 | 做法差异 |
| 妄想离奇 | 言语逻辑 | 注意状态 |

## 阶段 C — 题面改写检查表

### C1 语病（逐题默读）

- [ ] 主问读得通，场景 + 核心问 + 讲述邀请衔接自然
- [ ] 追问能接在同一次经历上
- [ ] 无维度显性词点破

### C2 降 AI 感

| 禁用 | 定稿替代 |
|------|----------|
| 请回忆一次 / 跟我分享 | 麻烦讲一讲 / 拿一次经历具体讲讲 |
| 具体说说 | 说说当时发生了什么 / 简单讲讲来龙去脉 |
| 快速适应过来 | （刻板）交给别人做 / 别人做法不同怎么看 |

### C3 跨维去模板化

7 题并排：不宜 3 题以上共用同一开头或同一「有没有…经历？」句式。

## 易混维度 · 主问区分（定稿）

| 易混对 | 定稿区分 |
|--------|----------|
| 冲动违规 vs 刻板固执 | 冲动：对**正常规矩**感到束缚、实际不太按规矩做；刻板：**交给别人**做是否放心 |
| 焦虑不安 vs 抑郁悲观 | 焦虑：**压力感**与应对；抑郁：**满意的事**与自我评价 |
| 偏执多疑 vs 刻板固执 | 偏执：中性场面**读成议论/话里有话**；刻板：**交托**后是否检查重做 |
| 行为古怪 vs 抑郁悲观 | 行为古怪：**对方反应**与表达条理；抑郁：**自我评价**与说话过程 |

## 妄想离奇

```
不建议直接提问，面试中自然观察。

关键考察点（面试过程中自然观察，不作结论）：
1.言语逻辑：…
2.注意状态：…
3.独自言语：…
4.情感协调：…
```

不写「不适合出题的原因」长段（定稿已精简）；观察点仅过程表现，不作结论。
