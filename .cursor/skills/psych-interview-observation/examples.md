# 题本示例（用户终稿）

完整 8 维定稿见 [用户终稿.md](../../用户终稿.md)。以下为结构要点。

## 提问方式

| 维度 | 切入 | 核心问 | 讲述邀请 |
|------|------|--------|----------|
| 抑郁悲观 | 学习、实习或是日常工作里 | 特别满意、事后仍觉得很好 | 麻烦讲一讲…具体是什么情形 |
| 焦虑不安 | 大家都会有压力比较大 | 什么情况下特别有这种感觉 | 拿一次经历具体讲讲 |
| 冲动违规 | 平时上学、实习或者上班 / 日常生活 | 大家认为正常的规矩，你却感到束缚 | 结合具体一件事，说说发生了什么 |
| 行为古怪 | 和同学、同事一起商量事情 | 对方反应和预想很不一样 | 说说遇到的具体经历 |
| 偏执多疑 | 学习、实习或是日常工作里 | 和一组人搭班相处 | 事后想想挺不舒服的事 |
| 喜怒无常 | 最近 | 情绪波动大或憋屈难受 | 简单讲讲来龙去脉 |
| 刻板固执 | 一起干活需要分工 | 把事交给别人做 | 有没有这样的经历，拿一次讲讲 |

## 追问方式

- 同一经历延伸一层，宜短：「被指出以后你怎么想的」「你后来怎么看」「一般会怎么应对」
- 不必每题都问「心里感受」；刻板可合并两问：「别人做法不同怎么看 + 会不会检查重做」

## 考察点（每维 2 条）

```
1.四字关键词：可观察表现1；可观察表现2
2.四字关键词：可观察表现1；可观察表现2
```

妄想离奇 4 条过程观察，不出题。
