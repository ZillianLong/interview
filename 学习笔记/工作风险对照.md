# 工作风险 · 各维度对照表

> 来源：`工作表现.xlsx`  
> 用途：阶段 A 研究、学习笔记「工作风险线」、阶段 D 考察点命名与描述须与本表子维度对应

## 使用方式

1. **阶段 A**：读取当前维度低/中/高三档工作表现，写入该维学习笔记的「工作风险线」。
2. **阶段 B**：主问/追问应能引出表中 **1–2 个子维度** 的可观察信号（如冲动违规→规则执行；刻板固执→自己换做法，而非包揽分工）。
3. **阶段 D**：考察点 **四字关键词优先采用本表子维度名称**；描述覆盖低→中→高梯度表现，便于 HR 对照岗位风险。

## 抑郁悲观

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 出勤情况 | 出勤较稳定，偶尔请假 |
| 低 | 接活反应 | 安排任务偶犹豫，主动性尚可 |
| 中 | 出勤情况 | 请假偏多，原因不太明确 |
| 中 | 接活反应 | 容易打退堂鼓，主动性偏弱 |
| 高 | 出勤情况 | 出勤不稳定，可能无故失联 |
| 高 | 接活反应 | 经常推脱，反复说干不了、不想接 |

**面试对应**：接活反应、自我评价（接活/推脱线索）

## 焦虑不安

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 干活状态 | 偶不够踏实，效率略受影响 |
| 低 | 任务沟通 | 偶多次确认，沟通效率还行 |
| 中 | 干活状态 | 经常不踏实、分心，质量时好时坏 |
| 中 | 任务沟通 | 经常反复确认，比较担心出错 |
| 高 | 干活状态 | 长期紧绷，很难专心 |
| 高 | 任务沟通 | 已确认的事还反复追问，影响推进 |

**面试对应**：干活状态、任务沟通、担忧特点、难以放松

| 低 | 规则执行 | 偶图省事不完全按流程，影响有限 |
| 低 | 行为控制 | 遇问题可能有情绪，偶与同事冲突 |
| 中 | 规则执行 | 经常不按流程，不把规矩放心上 |

**面试对应**：规则执行、行为控制、指出反应、改法态度

## 行为古怪

|------|--------|------------------|
| 低 | 沟通效率 | 较少表达不清，沟通基本顺畅 |
| 低 | 团队协作 | 偶有点不一样，较少影响搭班 |
| 中 | 沟通效率 | 经常说不明白，沟通吃力 |

**面试对应**：沟通效率、团队协作、本人看法、面试表现

## 偏执多疑

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 管理配合 | 偶误解安排，配合度还可 |
| 低 | 团队协作 | 偶误会工友意思 |
| 中 | 管理配合 | 常把安排理解成故意针对 |
| 中 | 团队协作 | 常需澄清误会，推进变慢 |
| 高 | 管理配合 | 长期认为被针对，配合度低 |
| 高 | 团队协作 | 长期因误解拒绝配合 |

**面试对应**：管理配合、团队协作、说话方式、回答详略

## 喜怒无常

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 工作状态 | 偶情绪不好，较少带到工作 |
| 低 | 团队协作 | 偶有情绪波动，合作尚可 |
| 中 | 工作状态 | 情绪时好时坏，影响进度 |
| 中 | 团队协作 | 忽冷忽热、甩脸色，影响搭班 |
| 高 | 工作状态 | 情绪频繁，常耽误进度 |
| 高 | 团队协作 | 易翻脸、起冲突，打乱搭班 |

**面试对应**：工作状态、团队协作、恢复时长、事后看法

## 刻板固执

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 干活习惯 | 有自己的习惯，偶固执，灵活性尚可 |
| 低 | 效率进度 | 偶因坚持习惯略影响效率 |
| 中 | 干活习惯 | 坚持熟悉方法，不太愿按规定灵活调整 |
| 中 | 效率进度 | **不信任他人成果，别人做完也要重做** |
| 高 | 干活习惯 | 固守自己程序，一点不能变 |
| 高 | 效率进度 | **要求工友完全按自己步骤来** |

**面试对应**：
- **主问**触「自己换做法/按新步骤自己做」（干活习惯、效率进度），**勿**主问「愿不愿意交给别人做」——后者是中高风险 **他人信任** 线索，放在考察点或候选人主动提及时记录。
- 考察点：干活习惯、效率进度、他人信任、做完惦记

## 妄想离奇（表中为「妄想倾向」）

| 风险 | 子维度 | 工作表现（摘要） |
|------|--------|------------------|
| 低 | 安全作业 | 多数按规定操作 |
| 低 | 团队影响 | 较少说不真实的话 |
| 中 | 安全作业 | 错觉导致操作失误风险 |
| 中 | 团队影响 | 经常说脱离实际的话 |
| 高 | 安全作业 | 长期错觉，错误频发，安全隐患 |
| 高 | 团队影响 | 坚信脱离实际的事，影响氛围 |

**面试对应**：安全作业、团队影响 + 过程观察（言语混乱、注意分散等）
